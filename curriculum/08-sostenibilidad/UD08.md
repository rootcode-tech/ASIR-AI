# ASIR-08 · UD08 — Plan de sostenibilidad para una infraestructura IT

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-08 · Tecnología Sostenible — Sostenibilidad

## 1. Objetivos

- integrar hardware, energía, residuos, compras, CPD/cloud e indicadores;
- priorizar acciones por impacto, coste y viabilidad;
- definir objetivos y métricas;
- construir un roadmap;
- identificar dependencias y riesgos;
- establecer responsables;
- plantear revisión periódica;
- defender un plan técnico de sostenibilidad.

## 4. Teoría

La sostenibilidad se convertirá en un plan operativo:

`baseline → objetivo → acción → responsable → indicador → fecha → revisión`

No se aceptarán planes basados solo en declaraciones generales.

## 5. Herramientas

Git/Markdown, hoja de cálculo, diagramas y dashboards sencillos.

## 6. Ejercicios

- priorizar acciones;
- diseñar KPIs;
- estimar costes/ahorros;
- detectar conflictos entre objetivos;
- construir roadmap.

## 7. Laboratorio

### Proyecto integrador

Crear un plan para una pyme o sede con:

- 30-100 puestos;
- servidores o cloud;
- red;
- almacenamiento;
- ciclo de renovación.

Debe incluir diagnóstico, objetivos, acciones, costes, indicadores, responsables y calendario.
