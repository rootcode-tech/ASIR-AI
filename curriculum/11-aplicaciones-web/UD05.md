# ASIR-11 · UD05 — Contenedores para aplicaciones web

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- comprender el uso de contenedores en despliegue web;
- construir imágenes sencillas;
- ejecutar servicios;
- gestionar puertos, volúmenes y variables;
- comprender persistencia;
- separar imagen de configuración;
- analizar logs;
- preparar Docker sin duplicar ASIR-16.

## 2. Conocimientos previos

ASIR-09 UD08 y UD01-UD04 de ASIR-11.

## 3. Contenidos

- image;
- container;
- Dockerfile;
- registry a nivel conceptual;
- build;
- run;
- port mapping;
- bind mounts;
- volumes;
- environment variables;
- logs;
- restart policy;
- healthcheck;
- multi-stage build a nivel contextual;
- non-root container como buena práctica.

## 4. Teoría

El contenedor se usará como unidad de empaquetado y ejecución, no como sustituto automático de la comprensión del servicio.

ASIR-16 profundizará Docker y Compose.

## 5. Herramientas

Docker/Podman, CLI, Git y registry local/público de laboratorio.

## 6. Ejercicios

- crear Dockerfile;
- mapear puertos;
- gestionar persistencia;
- analizar logs;
- identificar capas;
- corregir configuración.

## 7. Laboratorio

Containerizar una aplicación sencilla y conectarla a una base de datos externa o servicio de laboratorio.

## 8. Documentación y entregables

Dockerfile, instrucciones de build/run y diagrama.

## 9. Competencias transversales

- contenedores;
- Linux;
- Git;
- seguridad;
- reproducibilidad.

## 10. Criterios de dominio

- construir/ejecutar imagen;
- distinguir imagen/contenedor;
- persistir datos;
- pasar configuración sin hornearla;
- diagnosticar ejecución.

## 11. Preparación del examen

Tareas de construcción y operación.

## 12. Examen

- 60% práctica;
- 40% conceptos/diagnóstico.
