# ASIR-04 · UD06 — SQL DML: inserción, actualización y borrado

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-04 · Bases de Datos I — Gestión de Bases de Datos

## 1. Objetivos

- insertar datos correctamente;
- actualizar filas de forma controlada;
- eliminar datos comprendiendo dependencias;
- comprender efecto de filtros;
- evitar operaciones masivas accidentales;
- usar transacciones básicas para cambios;
- interpretar errores de integridad.

## 2. Conocimientos previos

UD05.

## 3. Contenidos

- DML;
- INSERT;
- múltiples filas;
- UPDATE;
- DELETE;
- WHERE;
- expresiones;
- NULL;
- DEFAULT;
- RETURNING cuando proceda;
- restricciones durante DML;
- transacciones de protección;
- operaciones idempotentes a nivel conceptual.

## 4. Teoría

Regla operativa:

**antes de UPDATE o DELETE, verificar con SELECT exactamente qué filas serán afectadas.**

Se introducirá el hábito de usar transacciones para cambios sensibles.

## 5. Herramientas

PostgreSQL, psql/cliente SQL y scripts versionados.

## 6. Ejercicios

- inserciones;
- actualizaciones simples y condicionadas;
- borrados;
- manejo de NULL;
- violaciones de FK;
- corrección de sentencias peligrosas.

## 7. Laboratorio

Cargar un conjunto de datos de prueba, aplicar cambios solicitados y revertir una operación incorrecta utilizando transacción.

## 8. Documentación y entregables

- `seed.sql`;
- `changes.sql`;
- registro de pruebas.

## 9. Competencias transversales

- Git;
- seguridad operacional;
- reproducibilidad;
- troubleshooting.

## 10. Criterios de dominio

- modificar datos sin afectar filas no previstas;
- explicar NULL;
- interpretar errores de FK/constraints;
- usar transacciones para proteger cambios;
- escribir scripts repetibles cuando proceda.

## 11. Preparación del examen

DML sobre un esquema conocido y corrección de errores.

## 12. Examen

- 70% SQL práctico;
- 30% seguridad y diagnóstico de cambios.
