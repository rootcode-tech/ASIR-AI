## 1. Objetivos

- comprender cómo se publica y consume un servicio de red;

## 4. Teoría

Un servicio accesible requiere que varias condiciones sean verdaderas:

`proceso activo → socket escuchando → interfaz correcta → firewall permite → routing funciona → DNS apunta bien → aplicación responde`

Esta cadena será la base del diagnóstico del módulo.
