# ASIR-01 · UD01 — Arquitectura de computadores y fundamentos de sistemas operativos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-01 · Sistemas I — Implantación de Sistemas Operativos

## 1. Objetivos

Al finalizar la unidad el alumno deberá ser capaz de:

- explicar la función de CPU, memoria, buses, almacenamiento y dispositivos de E/S desde la perspectiva del sistema operativo;
- distinguir kernel, espacio de usuario, procesos, hilos, llamadas al sistema y controladores;
- describir el ciclo básico de ejecución de una instrucción y su relación con procesos;
- diferenciar arquitecturas x86-64 y ARM a nivel conceptual;
- comprender modos privilegiado/no privilegiado, interrupciones y excepciones;
- comparar sistemas operativos monolíticos, modulares y de microkernel a nivel introductorio;
- relacionar recursos físicos con abstracciones del sistema operativo.

## 2. Conocimientos previos

- ASIR-00 recomendado.

## 3. Contenidos

### 3.1 Conceptos

- arquitectura de computador;
- CPU, registros, caché y memoria principal;
- jerarquía de memoria;
- buses e interfaces;
- dispositivos y controladores;
- firmware, UEFI y arranque;
- kernel y user space;
- proceso, hilo y contexto;
- llamadas al sistema;
- interrupciones y excepciones;
- multitarea y planificación;
- memoria virtual a nivel conceptual;
- sistemas operativos de escritorio, servidor y embebidos.

### 3.2 Procedimientos

- identificar componentes de un sistema real;
- consultar información de CPU, RAM, firmware y almacenamiento;
- relacionar un proceso con recursos consumidos;
- distinguir información de hardware de información del SO;
- leer documentación técnica básica de arquitectura.

### 3.3 Diagnóstico

Errores y confusiones frecuentes:

- confundir CPU con núcleo lógico;
- confundir RAM con almacenamiento;
- asumir que un proceso es un programa estático;
- pensar que el kernel es “todo el sistema operativo”;
- interpretar arquitectura de CPU y arquitectura del SO como equivalentes;
- confundir firmware, bootloader y kernel.

## 4. Teoría

Esta unidad crea el vocabulario técnico de toda la asignatura. Antes de instalar sistemas se debe comprender **qué abstrae el sistema operativo y qué recursos administra**.

Se introducirá el recorrido:

`hardware → firmware → bootloader → kernel → servicios → sesión de usuario → aplicaciones`

sin entrar todavía en configuraciones avanzadas.

## 6. Ejercicios

1. Etiquetar un diagrama de arquitectura.
2. Diferenciar proceso, hilo y programa.
3. Clasificar componentes como hardware, firmware, kernel, servicio o aplicación.
4. Comparar dos CPUs a partir de especificaciones.
5. Explicar qué ocurre desde el encendido hasta abrir una aplicación.
6. Interpretar salidas reales de inventario de sistema.

## 7. Laboratorio

### Objetivo

Construir una ficha técnica completa de dos equipos virtuales o físicos.

### Tareas

1. Identificar CPU, arquitectura, memoria y almacenamiento.
2. Identificar firmware y modo de arranque.
3. Enumerar procesos y consumo.
4. Capturar información desde Windows y GNU/Linux.
5. Comparar similitudes y diferencias.

### Validación

La ficha debe distinguir correctamente recursos físicos, abstracciones del SO y herramientas usadas.
