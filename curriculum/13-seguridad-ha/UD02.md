# ASIR-13 · UD02 — Hardening de sistemas y gestión de configuración segura

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-13 · Ciberseguridad y Alta Disponibilidad

## 1. Objetivos

- reducir superficie de ataque;
- aplicar mínimo privilegio;
- deshabilitar servicios innecesarios;
- endurecer Linux y Windows;
- comprender baselines;
- detectar configuration drift;
- gestionar parches;
- validar que el hardening no rompe operación.

## 2. Conocimientos previos

ASIR-09 completo.

## 3. Contenidos

- hardening;
- baselines;
- cuentas;
- servicios;
- permisos;
- sudo/UAC;
- firewall local;
- SSH/WinRM;
- logging;
- patching;
- secure defaults;
- CIS-like benchmarks como referencia;
- drift;
- exception management;
- rollback.

## 4. Teoría

Hardening = reducir exposición sin perder operabilidad.

Se trabajará:

`baseline → cambio → validación → evidencia → rollback`

## 5. Herramientas

Linux/Windows nativos, scripts de auditoría y documentación de referencia.

## 6. Ejercicios

- revisar servicios;
- corregir permisos;
- endurecer acceso remoto;
- comparar baseline;
- analizar excepciones.

## 7. Laboratorio

Endurecer un servidor Linux y otro Windows deliberadamente inseguros.

## 8. Documentación y entregables

Checklist antes/después y excepciones justificadas.

## 9. Competencias transversales

- Linux;

- troubleshooting.

## 10. Criterios de dominio

- aplicar hardening reversible;
- detectar drift;
- justificar excepciones;
- validar funcionamiento;
- documentar cambios.

Casos de configuración segura.
