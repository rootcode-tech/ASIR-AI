# ASIR-01 · UD02 — Virtualización de laboratorio y gestión de máquinas virtuales

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-01 · Sistemas I — Implantación de Sistemas Operativos

## 1. Objetivos

- explicar qué es la virtualización y qué problema resuelve;
- distinguir hipervisores tipo 1 y tipo 2;
- crear y configurar máquinas virtuales;
- asignar CPU, RAM, disco y red de forma razonable;
- usar snapshots con criterio;
- comprender diferencias entre snapshot, clon y backup;
- gestionar imágenes ISO y plantillas;
- documentar un laboratorio reproducible.

## 4. Teoría

La virtualización será el **entorno de laboratorio principal** porque permite practicar sin comprometer el sistema anfitrión.

Se introducirá la disciplina:

`crear → documentar → cambiar → validar → snapshot si procede → revertir`

pero se insistirá en que un snapshot **no sustituye a una copia de seguridad**.

## 6. Ejercicios

1. Diseñar recursos para tres VMs con un host limitado.
2. Clasificar casos adecuados/no adecuados para snapshot.
3. Comparar NAT, bridge y host-only.
4. Analizar errores de sobreasignación.
5. Explicar la diferencia entre VM, contenedor y proceso.

## 7. Laboratorio

Crear dos VMs:

- GNU/Linux;
- Windows.

Configurar:

- 2 vCPU;
- memoria razonable;
- disco;
- ISO;
- red NAT y una segunda red privada;
- snapshots de puntos significativos.
