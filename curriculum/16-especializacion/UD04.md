# ASIR-16 · UD04 — Docker Compose y stacks multi-servicio

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- definir stacks declarativos;
- comprender services/networks/volumes;
- gestionar dependencias;
- usar variables;
- separar configuración por entorno;
- utilizar healthchecks;
- gestionar persistencia;
- desplegar stacks completos;
- operar upgrades y rollback básicos.

## 2. Conocimientos previos

UD03 y ASIR-11.

## 4. Teoría

Compose será el puente entre contenedor individual y plataforma orquestada.

Principio:

`servicio + red + persistencia + configuración + dependencia = stack reproducible`

## 5. Herramientas

Docker Compose, Git y shell.

## 6. Ejercicios

- diseñar stacks;
- separar redes;
- gestionar variables;
- corregir dependencias;
- actualizar imágenes;
- interpretar logs.

## 7. Laboratorio

Desplegar un stack con reverse proxy, aplicación y PostgreSQL, con redes separadas, persistencia y healthchecks.
