# ASIR-09 · UD06 — Automatización con Bash y PowerShell

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-09 · Sistemas II — Administración de Sistemas Operativos

## 1. Objetivos

- escribir scripts robustos para administración;
- usar variables, condiciones, bucles y funciones;
- procesar argumentos;
- manejar errores y códigos de salida;
- leer/escribir ficheros;
- trabajar con objetos en PowerShell;
- crear scripts idempotentes cuando sea razonable;
- registrar acciones;
- no incrustar secretos.

## 2. Conocimientos previos

ASIR-01 UD05/UD08 y UD01/UD02 de ASIR-09.

## 4. Teoría

La automatización debe ser:

- legible;
- repetible;
- verificable;
- segura;
- reversible cuando sea posible.

No se considerará buen script una secuencia de comandos copiados sin control de errores.

## 5. Herramientas

Crear dos scripts equivalentes, uno Bash y otro PowerShell, para inventariar hosts y producir salida estructurada.
