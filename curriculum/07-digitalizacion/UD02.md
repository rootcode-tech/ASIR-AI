# ASIR-07 · UD02 — Sistemas IT/OT, conectividad y plataformas

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-07 · Transformación Digital — Digitalización

## 1. Objetivos

- distinguir IT y OT;
- comprender sistemas ciberfísicos a alto nivel;
- identificar sensores, actuadores y gateways;
- comprender conectividad entre edge y sistemas centrales;
- reconocer riesgos de integración IT/OT;
- interpretar arquitecturas de plataforma;
- distinguir componentes de adquisición, procesamiento y explotación de datos.

## 2. Conocimientos previos

UD01 y ASIR-02 recomendada.

## 3. Contenidos

- IT;
- OT;

- sistemas ciberfísicos;

## 4. Teoría

Se estudiará la cadena:

`sensor/activo → gateway/edge → red → plataforma → dato → decisión`

destacando que OT prioriza continuidad y seguridad física además de confidencialidad.

## 5. Herramientas

Diagramas de arquitectura, simuladores conceptuales y documentación técnica.

## 6. Ejercicios

- clasificar sistemas IT/OT;
- identificar puntos de integración;
- diseñar flujos de telemetría;
- detectar riesgos;
- proponer segmentación.

## 7. Laboratorio

Diseñar una arquitectura para monitorizar temperatura, energía y estado de una sala técnica mediante sensores, gateway y plataforma central.

## 8. Documentación y entregables

Diagrama y matriz componente/función/riesgo.

## 9. Competencias transversales

- redes;
- seguridad;
- observabilidad;
- arquitectura.

## 10. Criterios de dominio

- distinguir IT/OT;
- explicar edge;
- modelar un flujo de telemetría;
- identificar riesgos de integración;
- justificar separación de redes.

## 11. Preparación del examen

Escenarios de arquitectura IT/OT.

## 12. Examen
