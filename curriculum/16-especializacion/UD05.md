# ASIR-16 · UD05 — CI/CD con pipelines y quality gates

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- diseñar pipelines profesionales;
- separar CI, delivery y deployment;
- automatizar lint/test/build;
- gestionar artefactos;
- construir imágenes;
- usar environments y approvals;
- proteger secretos;
- aplicar quality gates;
- diseñar rollback;
- comprender runners y permisos.

## 4. Teoría

Pipeline de referencia:

`commit → lint → test → build → scan → artifact/image → staging → acceptance → approval → production`

El pipeline debe fallar temprano y dejar evidencia.

## 5. Herramientas

GitHub Actions como referencia, GitHub Packages/registry o equivalente y shell.

## 6. Ejercicios

- diseñar workflows;
- proteger secretos;
- usar artifacts;
- crear matrices;
- definir gates;
- analizar fallos.

## 7. Laboratorio

Construir pipeline completo para una aplicación containerizada con test, build, scan defensivo, publicación y despliegue a staging.

## 8. Documentación y entregables

Workflow, diagrama y política de gates.

## 9. Competencias transversales

- usar quality gates;

Lectura y diseño de pipelines.
