# ASIR-01 · UD03 — Instalación, arranque, particionado y despliegue de sistemas

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-01 · Sistemas I — Implantación de Sistemas Operativos

## 1. Objetivos

- preparar un sistema para instalación;
- verificar imágenes de instalación;
- distinguir BIOS heredada y UEFI;
- comprender GPT y MBR;
- planificar particiones;
- instalar GNU/Linux y Windows;
- explicar el flujo de arranque;
- recuperar fallos básicos de bootloader;
- documentar un despliegue reproducible.

## 2. Conocimientos previos

UD01 y UD02.

## 3. Contenidos

- medios de instalación;
- ISO y checksum;
- UEFI;
- Secure Boot a nivel conceptual;
- GPT y MBR;
- ESP;
- particiones;
- bootloader;
- instalación interactiva;
- instalación mínima/servidor;
- hostname;
- zona horaria;
- locale;
- usuario inicial;
- actualizaciones;
- controladores;
- dual boot a nivel conceptual;
- arranque y recuperación básica.

## 4. Teoría

La instalación no se tratará como “siguiente, siguiente, finalizar”. Cada decisión deberá justificarse:

- modo de arranque;
- tabla de particiones;
- filesystem;
- usuario;
- red;
- paquetes;
- seguridad inicial.

## 5. Herramientas

- instaladores oficiales de Debian/Ubuntu Server y Windows;
- `sha256sum` / PowerShell `Get-FileHash`;
- utilidades de particionado;
- consola de recuperación.

## 6. Ejercicios

- diseñar particionado para varios escenarios;
- identificar errores de GPT/MBR;
- ordenar el flujo de arranque;
- interpretar una partición EFI;
- comparar instalación desktop/server/minimal.

## 7. Laboratorio

Instalar desde cero:

1. GNU/Linux servidor.
2. Windows.
3. Documentar particiones.
4. Aplicar actualizaciones.
5. Verificar arranque.
6. Realizar un snapshot post-instalación limpio.

## 8. Documentación y entregables

- guía de instalación propia;
- tabla de particiones;
- checklist post-instalación;
- evidencia de verificación de ISO.

## 9. Competencias transversales

- seguridad: verificación de imágenes;
- documentación;
- Linux;
- Windows;
- Git: versionado del procedimiento.

## 10. Criterios de dominio

- explicar UEFI/GPT/ESP;
- instalar ambos sistemas sin asistencia constante;
- justificar particionado;
- detectar errores básicos de arranque;
- verificar una ISO.

## 11. Preparación del examen

Diseños de instalación y análisis de escenarios.

## 12. Examen

- 30% arquitectura de arranque;
- 30% particionado;
- 40% caso práctico de despliegue/diagnóstico.
