# ASIR-07 · UD01 — Transformación digital, procesos y madurez tecnológica

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-07 · Transformación Digital — Digitalización

## 1. Objetivos

- comprender qué significa transformación digital más allá de digitalizar documentos;
- distinguir proceso, procedimiento, dato y servicio;
- identificar ineficiencias y cuellos de botella;
- modelar procesos sencillos;
- comprender niveles de madurez digital;
- relacionar tecnología con impacto organizativo;
- formular objetivos medibles de mejora.

## 4. Teoría

La transformación digital se estudiará como rediseño de procesos apoyado en tecnología.

Modelo:

`proceso actual → problema → dato → tecnología → cambio → indicador → mejora`

No se aceptará “usar una app” como transformación si el proceso subyacente sigue siendo ineficiente.

3. propuesta digital;
4. métricas de éxito;
5. riesgos.
