# ASIR-16 · UD03 — Docker: imágenes, contenedores, redes y volúmenes

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- administrar Docker de forma profesional;
- construir imágenes reproducibles;
- comprender capas;
- usar registries;
- gestionar redes;
- gestionar volúmenes;
- aplicar healthchecks;
- reducir privilegios;
- analizar logs y recursos;
- comprender ciclo de vida completo.

## 2. Conocimientos previos

ASIR-09 UD08 y ASIR-11 UD05.

## 4. Teoría

La imagen debe ser:

- reproducible;
- mínima;
- sin secretos;
- versionada;
- verificable.

Se separará claramente imagen, configuración y datos persistentes.

## 5. Herramientas

Docker Engine, Docker CLI, registry y Git.

## 6. Ejercicios

- optimizar Dockerfile;
- gestionar tags;
- crear redes;
- persistir datos;
- configurar healthcheck;
- analizar logs;
- limitar recursos.

## 7. Laboratorio

Construir y publicar una imagen propia, desplegarla con red y volumen, y validar healthcheck y persistencia.
