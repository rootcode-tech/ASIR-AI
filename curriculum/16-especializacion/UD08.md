# ASIR-16 · UD08 — Cloud: IAM, redes, compute, storage y costes

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- administrar fundamentos cloud de forma práctica;
- comprender cuentas/proyectos/subscriptions;
- diseñar IAM;
- desplegar redes virtuales;
- usar compute y storage;
- comprender load balancing y servicios gestionados;
- aplicar tagging;
- controlar costes;
- automatizar con IaC;
- comprender responsabilidad compartida.

## 2. Conocimientos previos

ASIR-07 UD04 y UD07 de ASIR-16.

## 3. Contenidos

- cloud account/project;
- IAM;
- users/roles/service identities;
- VPC/VNet;
- subnets;
- routing;
- security groups/firewalls;
- public/private IP;
- compute;
- object/block storage;
- load balancer;
- managed database conceptual;
- regions/zones;
- tags;
- budgets;
- cost alerts;
- shared responsibility;
- availability.

## 4. Teoría

Cloud se administrará como infraestructura programable y medida.

Toda arquitectura deberá justificar:

- identidad;
- red;
- seguridad;
- disponibilidad;
- coste;
- operación.

## 5. Herramientas

Un proveedor cloud principal para prácticas, CLI cuando proceda, Terraform y calculadoras de coste.

## 6. Ejercicios

- diseñar IAM;
- construir redes;
- comparar storage;
- calcular costes;
- detectar exposición pública;
- diseñar tagging.

## 7. Laboratorio

Desplegar mediante Terraform una pequeña aplicación cloud con red privada/pública, compute, storage y controles de acceso.

## 8. Documentación y entregables

Arquitectura, IaC, presupuesto estimado y teardown verificado.

## 9. Competencias transversales

- cloud;
- IAM;
- redes;
- IaC;
- FinOps;
- seguridad.

## 10. Criterios de dominio

- diseñar IAM mínimo;
- desplegar red;
- controlar exposición;
- estimar costes;
- automatizar creación/destrucción.

## 11. Preparación del examen

Arquitecturas y costes cloud.

## 12. Examen

- 20% IAM;
- 25% redes;
- 20% compute/storage;
- 20% seguridad/disponibilidad;
- 15% costes.
