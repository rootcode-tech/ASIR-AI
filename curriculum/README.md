# Curriculum

Este directorio contiene la definición académica de ASIR-AI.

- `CURRICULUM_MASTER.md`: mapa pedagógico global.
- `curriculum.yml`: metadatos estructurados.
- Cada subdirectorio corresponde a una asignatura.
- Cada UD se mantiene como `UD01.md`, `UD02.md`, etc.

## Desarrollo secuencial

Las 18 asignaturas tienen mapa curricular, pero **no es necesario desarrollar todas a nivel de impartición antes de estudiar**.

La regla vigente es:

```text
cerrar asignatura activa
→ estudiar teoría completa
→ ejercicios
→ laboratorios
→ repaso/simulacros
→ examen final solo a petición
→ recuperación si procede
→ desarrollar la siguiente asignatura
```

ASIR-00 es la asignatura activa inicial. ASIR-01 no se abre como siguiente bloque de estudio hasta que ASIR-00 esté aprobado.

Las reglas de operación están en `../AGENTS.md` y `../docs/LEARNING_MODEL.md`.
