# ASIR-17 · UD01 — Problema, requisitos, alcance y criterios de aceptación

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-17 · Proyecto ASIR-AI

## 1. Objetivos

- definir un problema técnico realista;
- identificar stakeholders;
- separar necesidades, requisitos y deseos;
- delimitar alcance;
- identificar restricciones;
- definir criterios de aceptación;
- gestionar supuestos;
- registrar riesgos iniciales;
- preparar un backlog de proyecto.

## 4. Teoría

El proyecto empieza por definir correctamente qué problema se quiere resolver.

Modelo:

`problema → requisito → criterio de aceptación → evidencia`

No se aceptará diseñar tecnología antes de cerrar necesidades y alcance.

## 5. Herramientas

Markdown, GitHub Issues/Projects, diagramación y plantillas de requisitos.

## 6. Ejercicios

- detectar requisitos ambiguos;
- convertir deseos en criterios verificables;
- identificar fuera de alcance;
- priorizar;
- registrar riesgos;
- preparar backlog.
