# ASIR-11 · UD10 — Observabilidad, pruebas y proyecto de despliegue completo

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- integrar todo ASIR-11;
- definir health checks y métricas;
- utilizar logs para diagnóstico;
- comprender disponibilidad y latencia;
- diseñar pruebas de aceptación;
- desplegar una aplicación completa;
- automatizar validaciones;
- documentar arquitectura, operación y recuperación;
- realizar troubleshooting extremo a extremo.

## 2. Conocimientos previos

UD01-UD09.

## 3. Contenidos

- logs de web/app/DB;
- métricas;
- health/readiness a nivel introductorio;
- uptime;
- latencia;
- error rate;
- synthetic tests;
- acceptance tests;
- dashboard;
- alerta;
- deployment;
- CI/CD;
- backup;
- restore;
- rollback;
- incident response;
- runbook.

## 4. Teoría

El despliegue se considerará terminado solo cuando la aplicación sea:

- accesible;
- segura;
- observable;
- recuperable;
- reproducible;
- documentada.

## 5. Herramientas

Nginx, runtime/app, PostgreSQL, Docker cuando proceda, GitHub Actions, curl, logs y stack de monitorización introductorio.

## 6. Ejercicios

- definir SLI básicos;
- diseñar health checks;
- interpretar logs;
- construir pruebas;
- analizar fallos encadenados;
- revisar arquitectura.

## 7. Laboratorio

### Proyecto de despliegue completo

Desplegar una aplicación con:

- DNS;
- HTTPS;
- reverse proxy;
- runtime o contenedor;
- base de datos;
- configuración/secretos;
- CI/CD introductorio;
- backups;
- health checks;
- logs;
- pruebas;
- procedimiento de rollback.

Provocar incidencias y recuperar el servicio.
