# ASIR-17 · UD03 — Repositorio, Git, documentación e Infrastructure as Code

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-17 · Proyecto ASIR-AI

## 1. Objetivos

- estructurar repositorio profesional;
- aplicar ramas, PR y releases;
- organizar documentación;
- usar ADR;
- incorporar Terraform/Ansible cuando proceda;
- separar código, configuración y secretos;
- definir convenciones;
- automatizar quality checks;
- mantener trazabilidad.

## 2. Conocimientos previos

ASIR-05, ASIR-16 UD01, UD06 y UD07.

## 3. Contenidos

- repo layout;
- README;
- docs/;
- infra/;
- ansible/;
- terraform/;
- app/;
- scripts/;
- environments;
- secrets;
- branch strategy;
- PR;
- release;
- SemVer;
- changelog;
- CI checks;
- ADR;
- contribution guidelines;
- reproducibility.

## 4. Teoría

El repositorio será la fuente de verdad operativa del proyecto, excepto secretos y datos sensibles.

## 5. Herramientas

Git, GitHub, Markdown, Ansible, Terraform/OpenTofu y CI.

## 6. Ejercicios

- diseñar estructura;
- crear policies;
- revisar secretos;
- escribir ADR;
- construir checks;
- versionar releases.

## 7. Laboratorio

Crear el repositorio definitivo del proyecto con estructura, convenciones, protecciones y automatizaciones básicas.

## 8. Documentación y entregables

Repositorio inicial, CONTRIBUTING/README, ADR template y pipeline de validación.

## 9. Competencias transversales

- Git/GitHub;
- IaC;
- documentación;
- seguridad.

## 10. Criterios de dominio

- mantener repo coherente;
- proteger secretos;
- usar PR;
- documentar decisiones;
- preparar infraestructura reproducible.

## 11. Preparación del examen

Repositorios y flujos de cambio.

## 12. Examen

- 50% diseño de repo;
- 30% Git/IaC;
- 20% seguridad/documentación.
