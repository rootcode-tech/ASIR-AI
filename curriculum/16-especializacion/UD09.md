# ASIR-16 · UD09 — Kubernetes: arquitectura y operación introductoria

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- comprender por qué existe un orquestador;
- conocer arquitectura de Kubernetes;
- distinguir cluster, node, pod y controller;
- desplegar workloads básicos;
- publicar servicios;
- utilizar ConfigMaps y Secrets a nivel introductorio;
- comprender desired state y reconciliation;
- realizar troubleshooting básico;
- distinguir Kubernetes de Docker Compose.

## 2. Conocimientos previos

UD03-UD05 y fundamentos de redes/servicios.

## 3. Contenidos

- control plane;
- node;

- replica set;

- kubectl;
- ingress a nivel introductorio;
- persistent volume conceptual.

## 4. Teoría

Kubernetes se introduce para comprender orquestación, no para convertir el módulo en una certificación especializada.

Modelo:

`declaración deseada → control plane → reconciliación → estado observado`

## 5. Herramientas

Kubernetes local de laboratorio, kubectl y YAML.

## 6. Ejercicios

- leer manifests;
- desplegar pods/deployments;
- exponer services;
- escalar;
- revisar logs/events;
- realizar rollout/rollback.

## 7. Laboratorio

Desplegar una aplicación containerizada con Deployment, Service, ConfigMap, Secret de laboratorio y probes.
