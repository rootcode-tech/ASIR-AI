# ASIR-05 · UD07 — APIs, HTTP y representación de datos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-05 · Lenguajes y Datos — Lenguajes de Marcas y SGI

## 1. Objetivos

- comprender HTTP como protocolo de aplicación;
- distinguir cliente, servidor, recurso y representación;
- interpretar métodos, códigos de estado y cabeceras;
- comprender URI/URL;
- trabajar con JSON/XML en APIs;
- distinguir parámetros de consulta, path y cuerpo;
- comprender autenticación a nivel introductorio;
- consumir una API sencilla;
- interpretar errores.

## 2. Conocimientos previos

UD03 y UD06; ASIR-02 UD01 recomendado.

## 3. Contenidos

- HTTP/HTTPS;
- request/response;
- GET/POST/PUT/PATCH/DELETE;
- estados 2xx/3xx/4xx/5xx;
- headers;
- Content-Type;
- Accept;
- URI/URL;
- query/path;
- body;
- JSON/XML;
- API;
- REST introductorio;
- autenticación básica/token a alto nivel;
- paginación;
- rate limiting;
- idempotencia conceptual.

## 4. Teoría

Una API se estudiará como contrato entre sistemas, no como una URL que devuelve JSON.

Se separará transporte HTTP, contrato y representación de datos.

## 5. Herramientas

curl, cliente HTTP gráfico opcional, DevTools y documentación OpenAPI cuando exista.

## 6. Ejercicios

- interpretar requests/responses;
- elegir métodos;
- diagnosticar status codes;
- construir curl;
- analizar headers;
- diferenciar 400/401/403/404/500.

## 7. Laboratorio

Consumir una API pública o local segura: leer documentación, realizar GET, usar parámetros, interpretar headers, guardar JSON, extraer datos y documentar errores.

## 8. Documentación y entregables

Colección reproducible de comandos curl y breve informe de contrato.

## 9. Competencias transversales

- redes;
- APIs;
- automatización;
- documentación técnica;
- seguridad.

## 10. Criterios de dominio

- explicar request/response;
- seleccionar método/status;
- consumir API desde CLI;
- interpretar Content-Type;
- distinguir autenticación/autorización a alto nivel.

## 11. Preparación del examen

Casos de HTTP y lectura de documentación.

## 12. Examen

- 40% HTTP;
- 30% APIs;
- 30% práctica/diagnóstico.
