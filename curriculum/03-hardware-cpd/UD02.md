# ASIR-03 · UD02 — UEFI/BIOS, POST, arranque y configuración de firmware

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-03 · Hardware y CPD — Fundamentos de Hardware

## 1. Objetivos

- comprender el papel del firmware;
- diferenciar BIOS heredada y UEFI;
- explicar POST y secuencia inicial de arranque;
- interpretar opciones habituales de firmware;
- comprender Secure Boot y TPM a nivel funcional;
- actualizar firmware con precaución;
- diagnosticar fallos básicos de POST y arranque.

## 2. Conocimientos previos

UD01 y ASIR-01 UD03.

## 3. Contenidos

- firmware;
- BIOS y UEFI;
- POST;
- orden de arranque;
- CSM;
- Secure Boot;
- TPM;
- virtualización por hardware;
- perfiles de memoria;
- monitorización térmica;
- actualización de firmware;
- recuperación de configuración;
- códigos acústicos/LED.

## 4. Teoría

Secuencia conceptual:

`energía → firmware → POST → dispositivo de arranque → bootloader → kernel`

Se trabajará la diferencia entre firmware, cargador de arranque y sistema operativo.

## 5. Herramientas

Interfaz UEFI/BIOS, manual de placa y utilidades oficiales de firmware.

## 6. Ejercicios

- ordenar el flujo de arranque;
- identificar opciones críticas;
- interpretar síntomas de POST;
- distinguir Secure Boot y TPM;
- decidir cuándo una actualización está justificada.

## 7. Laboratorio

Documentar versión de firmware, orden de arranque, virtualización, Secure Boot y opciones principales sin modificar parámetros críticos.

## 8. Documentación y entregables

Checklist de firmware y procedimiento seguro de actualización.
