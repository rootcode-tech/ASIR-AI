# ASIR-00 · Prácticas y laboratorios

**Versión:** 0.1.0  
**Estado:** listo para impartir  
**Regla:** las prácticas no generan nota académica. Sirven para consolidar, verificar y diagnosticar.

## LAB-00-01 · Entorno personal de estudio

### Objetivo
Crear un sistema de estudio sostenible y trazable.

### Tareas
- crear un diario de aprendizaje en Markdown;
- crear una tabla de errores con fecha, UD, tipo de error, causa y acción correctiva;
- definir disponibilidad semanal realista;
- reservar bloques separados de teoría, práctica y repaso;
- registrar una línea base inicial sin convertirla en nota.

### Validación
- el horario cabe realmente en la semana;
- cada error tiene causa y siguiente acción;
- el alumno puede explicar el método sin leerlo.

## LAB-00-02 · Capacidad, ocupación y transferencia

### Escenario
Dispones de varios discos y enlaces con distintas capacidades y velocidades.

### Tareas
- calcular porcentaje ocupado/libre;
- convertir entre bits, bytes y prefijos;
- estimar tiempo teórico de transferencia;
- recalcular con eficiencias del 75%, 85% y 95%;
- comparar estimación y cálculo exacto;
- explicar por qué nominal y real pueden diferir.

### Validación
Todos los resultados incluyen procedimiento, unidad y comprobación aproximada.

## LAB-00-03 · Comparación de costes tecnológicos

### Escenario
Dos proveedores tienen precio fijo más coste variable por uso.

### Tareas
- construir una expresión algebraica para cada proveedor;
- encontrar el punto de igualdad;
- determinar intervalos donde cada uno conviene;
- representar una tabla de valores;
- justificar la decisión según tres perfiles de uso.

### Validación
La ecuación se resuelve a mano y se comprueba numéricamente.

## LAB-00-04 · Modelización mediante gráficas

### Escenario
Se proporciona una serie temporal de uso de almacenamiento y carga de CPU.

### Tareas
- representar los datos;
- identificar tramos de crecimiento/decrecimiento;
- calcular una pendiente media donde sea razonable;
- detectar un cambio anómalo;
- proponer una explicación sin confundir hipótesis con prueba.

### Validación
El alumno distingue observación, interpretación e hipótesis.

## LAB-00-05 · Diseño físico básico de una pequeña sala IT

### Escenario
Una sala rectangular debe albergar racks, canalizaciones y varios puntos de red.

### Tareas
- calcular superficie y volumen;
- usar escala en un croquis;
- estimar longitudes de cable;
- calcular una diagonal con Pitágoras;
- añadir margen razonado de cableado;
- documentar unidades y redondeos.

### Validación
No hay mezclas de unidades y el margen está justificado.

## LAB-00-06 · Análisis de métricas

### Escenario
Se proporcionan dos conjuntos de latencias y tiempos de respuesta.

### Tareas
- calcular media, mediana y rango;
- comparar estabilidad;
- detectar valores atípicos;
- elegir qué medida comunica mejor la experiencia real;
- interpretar un percentil proporcionado;
- redactar una conclusión que no exagere lo que demuestran los datos.

### Validación
La conclusión se apoya en métricas concretas.

## LAB-00-07 · Potencia, energía y autonomía

### Escenario
Pequeña instalación con servidor, switch, monitor y UPS.

### Tareas
- sumar potencia nominal;
- calcular consumo energético diario;
- estimar coste con un precio por kWh proporcionado;
- estimar autonomía ideal de UPS;
- aplicar una eficiencia proporcionada;
- explicar límites del modelo.

### Validación
Se mantienen coherentes W, kW, Wh y kWh.

## LAB-00-08 · Informe técnico breve

### Escenario
Se entrega un texto con una incidencia y datos redundantes.

### Tareas
- identificar hechos relevantes;
- descartar ruido;
- redactar un resumen;
- redactar una conclusión técnica;
- distinguir lo comprobado de lo hipotético;
- revisar claridad y ortografía.

### Validación
Otra persona debe poder entender qué ocurrió, qué se sabe y qué falta por comprobar.

## LAB-00-09 · Lectura funcional de documentación en inglés

### Escenario
Se proporciona un README o fragmento de manual técnico de dificultad básica.

### Tareas
- localizar requisitos;
- localizar pasos de instalación;
- interpretar un mensaje de error;
- identificar una advertencia de seguridad;
- resumir en español el procedimiento sin traducir literalmente cada frase;
- redactar en Markdown los pasos esenciales.

### Validación
El resultado conserva el significado técnico y no inventa instrucciones ausentes.

## LAB-00-10 · Simulacro integral y retrospectiva

### Objetivo
Entrenar el ciclo completo antes de una evaluación real.

### Tareas
- realizar un simulacro cronometrado;
- registrar tiempo por bloque;
- marcar preguntas dudosas sin detener el intento;
- revisar al final;
- corregir con guía;
- clasificar cada error;
- seleccionar tres acciones prioritarias;
- repetir posteriormente con un simulacro equivalente.

### Validación
No se busca solo mejorar la puntuación: debe mejorar la calidad del procedimiento y la gestión del tiempo.

## Gate de prácticas de ASIR-00

Antes del repaso final se espera que el alumno haya completado al menos una práctica representativa de cada bloque principal y pueda explicar:

- qué hizo;
- por qué lo hizo;
- cómo verificó el resultado;
- qué error cometió o podría cometer;
- cómo lo detectaría.
