# ASIR-11 · UD03 — Despliegue de aplicaciones con base de datos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- desplegar aplicaciones con persistencia;
- configurar conexión a base de datos;
- comprender migrations y seed a nivel funcional;
- separar esquema, datos y configuración;
- gestionar usuarios de base con mínimo privilegio;
- comprender pooling a nivel introductorio;
- diagnosticar errores de conexión.

## 2. Conocimientos previos

UD01-UD02 y ASIR-04.

## 3. Contenidos

- connection string;
- hostname/port/database/user;
- migrations;
- seed;
- schema;
- usuario de aplicación;
- privilegios;
- pooling;
- transacciones;
- timeout;
- charset/timezone;
- backup previo a cambios;
- rollback de despliegue.

## 4. Teoría

El despliegue de una aplicación no termina cuando “arranca”; debe garantizar integridad y reproducibilidad de los cambios de base de datos.

## 5. Herramientas

PostgreSQL, cliente SQL, runtime de aplicación y Git.

## 6. Ejercicios

- diseñar usuarios;
- interpretar errores;
- ordenar migrations;
- distinguir configuración/datos;
- analizar permisos excesivos.

## 7. Laboratorio

Desplegar una app conectada a PostgreSQL con usuario restringido, migrations y datos iniciales.

## 8. Documentación y entregables

Script de base, configuración de ejemplo y procedimiento de despliegue.

## 9. Competencias transversales

- SQL;
- seguridad;
- Git;
- backups;
- troubleshooting.

## 10. Criterios de dominio

- desplegar app + DB;
- aplicar mínimo privilegio;
- ejecutar migrations;
- diagnosticar conexión;
- documentar rollback.

## 11. Preparación del examen

Casos de persistencia y despliegue.

## 12. Examen

- 40% despliegue;
- 30% base de datos;
- 30% diagnóstico.
