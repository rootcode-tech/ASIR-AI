# ASIR-01 · UD08 — Administración básica de Windows y PowerShell

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-01 · Sistemas I — Implantación de Sistemas Operativos

## 1. Objetivos

- orientarse en la arquitectura administrativa de Windows;
- gestionar cuentas locales, grupos, servicios y procesos;
- comprender NTFS y permisos básicos;
- utilizar PowerShell como shell administrativa;
- descubrir comandos con ayuda integrada;
- trabajar con objetos y pipeline;
- consultar eventos;
- instalar o gestionar características básicas;
- comparar paradigmas Linux/Windows.

## 2. Conocimientos previos

UD01-UD07. No se exige conocimiento previo de PowerShell.

## 3. Contenidos

- Windows editions y componentes;
- cuentas locales;
- grupos;
- servicios;
- procesos;
- NTFS;
- Event Viewer;
- registro a nivel conceptual;
- PowerShell;
- cmdlets;
- Verb-Noun;
- objetos;
- pipeline;
- `Get-Help`;
- `Get-Command`;
- `Get-Member`;
- variables;
- navegación por proveedores;
- administración remota a nivel introductorio.

## 4. Teoría

PowerShell se enseñará como shell **orientada a objetos**, contrastándola con el pipeline de texto habitual de Unix.

Se buscará transferencia conceptual:

`proceso ↔ servicio ↔ log/evento ↔ identidad ↔ filesystem`

## 5. Herramientas

PowerShell, Windows Terminal, Event Viewer, Services, Computer Management.

## 6. Ejercicios

- descubrimiento de cmdlets;
- inventario de procesos/servicios;
- filtros;
- selección de propiedades;
- cuentas y grupos;
- permisos básicos;
- eventos.

## 7. Laboratorio

Preparar un Windows recién instalado:

1. inventario;
2. usuario/grupos;
3. servicio;
4. evento;
5. script corto de inventario PowerShell;
6. exportación de resultados.

## 8. Documentación y entregables

Script `.ps1`, salida documentada y comparación con comandos Linux equivalentes.

## 9. Competencias transversales

- PowerShell: introducción formal;
- Windows;
- automatización: introducción;
- observabilidad: eventos.

## 10. Criterios de dominio

- usar ayuda para descubrir comandos;
- filtrar objetos;
- gestionar servicios y procesos;
- localizar eventos;
- escribir un script pequeño y legible.

## 11. Preparación del examen

Tareas en consola y análisis de objetos/salidas.

## 12. Examen

- 60% PowerShell práctico;
- 20% administración;
- 20% comparación conceptual/diagnóstico.
