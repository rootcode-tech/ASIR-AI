# ASIR-15 · UD03 — Portfolio técnico, GitHub y evidencias verificables

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-15 · Carrera Profesional II — IPE II

## 1. Objetivos

- convertir aprendizaje en evidencias profesionales;
- diseñar un portfolio coherente;
- seleccionar proyectos relevantes;
- mejorar repositorios;
- redactar README profesionales;
- mostrar decisiones, pruebas y resultados;
- diferenciar proyecto demostrable de ejercicio;
- evitar publicar secretos o datos sensibles.

## 2. Conocimientos previos

Git/GitHub de ASIR-05 y proyectos de módulos técnicos.

## 3. Contenidos

- portfolio;
- repositorio;
- README;
- arquitectura;
- screenshots/diagramas;
- decisiones técnicas;
- ADR;
- issues;
- releases;
- changelog;
- tags;
- evidencias;
- demos;
- privacidad;
- secretos;
- licencia;
- contribuciones;
- narrativa profesional.

## 4. Teoría

Un portfolio fuerte demuestra:

`problema → decisión → implementación → validación → resultado → aprendizaje`

No se priorizará cantidad de repositorios, sino calidad y verificabilidad.

## 5. Herramientas

GitHub, Markdown, diagramas, GitHub Projects/Issues cuando aporten valor.

## 6. Ejercicios

- auditar repositorios;
- reescribir README;
- seleccionar evidencias;
- detectar información sensible;
- crear ADR;
- preparar releases.

## 7. Laboratorio

Transformar dos proyectos técnicos previos en piezas de portfolio con README, arquitectura, pruebas y resultados.

## 8. Documentación y entregables

Portfolio v1 y checklist de calidad de repositorios.

## 9. Competencias transversales

- Git/GitHub;
- documentación;
- comunicación;
- seguridad.

## 10. Criterios de dominio

- seleccionar evidencia útil;
- documentar decisiones;
- mantener repositorio limpio;
- proteger secretos;
- explicar proyecto a terceros.

## 11. Preparación del examen

Análisis de portfolios y repositorios.

## 12. Examen

- 40% conceptos;
- 60% evaluación de evidencia profesional.
