# ASIR-11 · UD07 — Configuración, secretos y entornos de despliegue

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- separar código, configuración y secretos;
- comprender entornos development/staging/production;
- gestionar variables de entorno;
- usar archivos de ejemplo sin exponer secretos;
- comprender configuración inmutable/dinámica a alto nivel;
- introducir secret stores;
- documentar parámetros;
- evitar drift entre entornos.

## 2. Conocimientos previos

UD01-UD06 y ASIR-05 UD06.

## 3. Contenidos

- configuración;
- secretos;
- variables de entorno;
- config files;
- archivos .env como patrón y sus riesgos;
- staging;
- production;
- defaults;
- feature flags a nivel introductorio;
- secret manager conceptual;
- rotation;
- least privilege;
- drift;
- configuration schema;
- validation.

## 4. Teoría

Regla:

**el repositorio puede contener la plantilla de configuración, pero no los secretos reales.**

Se trabajará la paridad entre entornos sin copiar credenciales.

## 5. Herramientas

Git, variables de entorno, secret files protegidos y gestores de secretos a nivel contextual.

## 6. Ejercicios

- detectar secretos;
- separar config;
- diseñar variables;
- comparar entornos;
- corregir drift;
- crear plantilla segura.

## 7. Laboratorio

Convertir una aplicación mal configurada en una aplicación portable entre dev/staging/prod sin secretos en Git.

## 8. Documentación y entregables

Catálogo de configuración y archivo de ejemplo.

## 9. Competencias transversales

- seguridad;
- Git;
- configuración;
- reproducibilidad.

## 10. Criterios de dominio

- separar código/config/secrets;
- no versionar credenciales;
- explicar entornos;
- validar configuración;
- diseñar rotación básica.

## 11. Preparación del examen

Análisis de repositorios/configuración.

## 12. Examen

- 40% conceptos;
- 30% diseño;
- 30% diagnóstico.
