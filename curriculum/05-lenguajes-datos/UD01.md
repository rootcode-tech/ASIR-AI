# ASIR-05 · UD01 — HTML semántico y estructura de documentos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-05 · Lenguajes y Datos — Lenguajes de Marcas y SGI

## 1. Objetivos

- comprender HTML como lenguaje de marcado semántico;
- construir documentos bien estructurados;
- diferenciar contenido, estructura y presentación;
- utilizar encabezados, listas, tablas, enlaces, imágenes y formularios básicos;
- comprender accesibilidad semántica elemental;
- validar documentos;
- interpretar el DOM a nivel introductorio.

## 2. Conocimientos previos

Competencia digital básica y ASIR-00 UD09 recomendada.

## 3. Contenidos

- documento HTML;
- doctype;
- head/body;
- metadatos;
- estructura semántica;
- headings;
- párrafos;
- listas;
- enlaces;
- imágenes;
- tablas;
- formularios básicos;
- atributos;
- entidades;
- validación;
- accesibilidad básica;
- DOM introductorio.

## 4. Teoría

HTML se estudiará como representación estructurada de información, no como herramienta visual. La regla será:

`contenido + significado → HTML`

y la presentación se delegará en CSS.

## 5. Herramientas

- editor de código;
- navegador y DevTools;
- validador HTML;
- Git/GitHub.

## 6. Ejercicios

- estructurar textos;
- crear tablas accesibles;
- construir navegación;
- formularios sencillos;
- corregir HTML inválido;
- mejorar semántica de páginas.

## 7. Laboratorio

Crear una pequeña documentación técnica estática con portada, índice, tablas, enlaces internos, imágenes y formulario de contacto ficticio.

## 8. Documentación y entregables

- archivos HTML;
- validación sin errores críticos;
- README del mini-sitio.

## 9. Competencias transversales

- Git/GitHub;
- documentación;
- accesibilidad;
- estructura de información.

## 10. Criterios de dominio

- producir HTML válido y semántico;
- separar estructura/presentación;
- usar elementos correctos según significado;
- interpretar estructura DOM básica.

## 11. Preparación del examen

Construcción y corrección de documentos.

## 12. Examen

- 60% práctica;
- 20% semántica;
- 20% validación/diagnóstico.
