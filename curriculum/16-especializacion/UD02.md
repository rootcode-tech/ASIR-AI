# ASIR-16 · UD02 — Linux para DevOps y automatización reproducible

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- consolidar Linux como plataforma de automatización;
- utilizar shell, procesos y filesystem con soltura;
- trabajar con SSH de forma segura;
- preparar hosts para automatización;
- gestionar paquetes y servicios de forma reproducible;
- comprender variables, PATH y entorno;
- utilizar herramientas CLI profesionales;
- automatizar sin introducir fragilidad.

## 4. Teoría

Un entorno DevOps reproducible requiere que un host pueda pasar de estado inicial a estado deseado mediante procedimientos claros y verificables.

## 5. Herramientas

Bash, SSH, systemd, curl, jq, Git y utilidades GNU.

## 6. Ejercicios

- preparar hosts;
- validar dependencias;
- automatizar tareas;
- procesar JSON/YAML;
- revisar logs;
- construir scripts idempotentes.

## 7. Laboratorio

Preparar desde cero dos servidores Linux para ser gestionados de forma remota y reproducible.
