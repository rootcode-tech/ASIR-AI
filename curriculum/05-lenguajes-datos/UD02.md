# ASIR-05 · UD02 — CSS esencial y presentación accesible

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-05 · Lenguajes y Datos — Lenguajes de Marcas y SGI

## 1. Objetivos

- aplicar estilos sin contaminar la estructura HTML;
- comprender selectores, cascada, especificidad y herencia;
- trabajar con box model;
- diseñar layouts básicos con flexbox/grid;
- adaptar contenido a distintos tamaños;
- aplicar criterios básicos de contraste y legibilidad;
- diagnosticar conflictos de CSS.

## 2. Conocimientos previos

UD01.

## 3. Contenidos

- selectores;
- cascada;
- especificidad;
- herencia;
- box model;
- unidades;
- tipografía;
- color;
- display;
- flexbox;
- grid introductorio;
- responsive design;
- media queries;
- estados;
- accesibilidad visual.

## 4. Teoría

Se estudiará CSS como sistema de reglas con prioridad. Antes de “probar valores”, el alumno debe comprender qué regla gana y por qué.

## 5. Herramientas

DevTools, editor y validadores/linting básicos.

## 6. Ejercicios

- resolver conflictos de cascada;
- construir layouts;
- adaptar tablas y formularios;
- mejorar contraste;
- corregir estilos frágiles.

## 7. Laboratorio

Aplicar una presentación responsive y accesible al mini-sitio de UD01 sin modificar innecesariamente la semántica HTML.

## 8. Documentación y entregables

CSS versionado y breve guía de decisiones visuales.

## 9. Competencias transversales

- accesibilidad;
- Git;
- troubleshooting visual;
- documentación.

## 10. Criterios de dominio

- explicar cascada/especificidad;
- construir layout básico;
- evitar estilos inline salvo justificación;
- detectar por qué una regla no se aplica.

## 11. Preparación del examen

Casos de corrección y construcción.

## 12. Examen

- 60% CSS práctico;
- 20% cascada/especificidad;
- 20% accesibilidad/diagnóstico.
