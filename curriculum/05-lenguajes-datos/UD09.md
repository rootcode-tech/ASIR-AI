# ASIR-05 · UD09 — Documentación técnica con Markdown y automatización de datos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-05 · Lenguajes y Datos — Lenguajes de Marcas y SGI

## 1. Objetivos

- redactar documentación técnica clara en Markdown;
- estructurar README, procedimientos y referencias;
- usar enlaces, tablas y bloques de código;
- versionar documentación con Git;
- comprender documentación como código;
- automatizar transformaciones sencillas de datos;
- trabajar con YAML/JSON desde scripts básicos;
- generar salidas reproducibles;
- preparar el uso profesional de Git en todo ASIR-AI.

## 2. Conocimientos previos

UD01-UD08 y competencia digital básica.

## 3. Contenidos

- Markdown;
- headings;
- listas;
- tablas;
- links;
- code fences;
- documentación orientada a tareas;
- README;
- changelog introductorio;
- Git: working tree, staging, commit, diff y log;
- repositorio remoto;
- ramas a nivel introductorio;
- gitignore;
- datos estructurados desde scripts;
- stdin/stdout;
- pipelines sencillos;
- reproducibilidad.

## 4. Teoría

Esta UD convierte Git y Markdown en herramientas permanentes del curso.

Reglas:

- documentación junto al trabajo;
- commits pequeños y descriptivos;
- no guardar secretos;
- distinguir fuente de verdad de artefactos generados;
- automatizar solo después de comprender manualmente.

## 5. Herramientas

Git, GitHub, editor Markdown, Bash/PowerShell y Python introductorio cuando sea útil.

## 6. Ejercicios

- crear README;
- corregir documentación ambigua;
- inicializar repositorio;
- staging/commit/diff;
- resolver exclusiones;
- transformar JSON/CSV mediante script guiado;
- generar un informe.

## 7. Laboratorio

Crear un pequeño repositorio con README, datos fuente JSON/YAML, script sencillo, salida generada, instrucciones reproducibles e historial de commits coherente.

## 8. Documentación y entregables

El propio repositorio es el entregable formativo.

## 9. Competencias transversales

- Git/GitHub: introducción formal;
- Markdown: consolidación;
- Python/Bash/PowerShell: introducción contextual;
- IA aplicada: revisión controlada;
- automatización.

## 10. Criterios de dominio

- crear y mantener documentación legible;
- realizar el flujo add/commit/diff/log;
- ignorar artefactos y secretos adecuadamente;
- leer formatos estructurados;
- reproducir una transformación siguiendo README.

## 11. Preparación del examen

Tareas de documentación, Git e interpretación de formatos.

## 12. Examen

Examen final de ASIR-05:

- 20% HTML/CSS;
- 25% XML/XSD/XPath/XSLT;
- 20% JSON/YAML/TOML;
- 20% HTTP/APIs/integración;
- 15% Markdown/Git/documentación.
