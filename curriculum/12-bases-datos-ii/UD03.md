# ASIR-12 · UD03 — Usuarios, roles, privilegios y separación de funciones

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-12 · Bases de Datos II — Administración de SGBD

## 1. Objetivos

- diseñar modelo de roles;
- aplicar mínimo privilegio;
- distinguir login role y group role;
- gestionar ownership;
- usar GRANT/REVOKE;
- separar administración, aplicación y lectura;
- comprender default privileges;
- auditar privilegios efectivos.

## 2. Conocimientos previos

ASIR-04 UD10 y UD02 de ASIR-12.

## 3. Contenidos

- roles;
- LOGIN/NOLOGIN;
- membership;
- ownership;
- schema privileges;
- table/sequence/function privileges;
- default privileges;
- search_path;
- SECURITY DEFINER a nivel conceptual;
- superuser;
- separación de funciones;
- cuentas de servicio;
- auditoría de permisos.

## 4. Teoría

Modelo recomendado:

`owner técnico ≠ usuario de aplicación ≠ usuario humano ≠ superusuario`

Se evitará ejecutar aplicaciones con privilegios de propietario.

## 5. Herramientas

psql, catálogos de sistema y scripts SQL.

## 6. Ejercicios

- diseñar jerarquías;
- analizar permisos;
- corregir exceso de privilegios;
- interpretar ownership;
- aplicar default privileges.

## 7. Laboratorio

Crear roles para:

- DBA;
- owner;
- aplicación;
- lectura;
- reporting.

Validar operaciones permitidas y denegadas.
