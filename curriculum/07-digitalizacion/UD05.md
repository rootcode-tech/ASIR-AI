# ASIR-07 · UD05 — Automatización, integración y APIs

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-07 · Transformación Digital — Digitalización

## 1. Objetivos

- comprender automatización de procesos;
- distinguir automatización, orquestación e integración;
- identificar tareas repetitivas automatizables;
- comprender flujos event-driven a nivel introductorio;
- relacionar APIs con automatización;
- comprender idempotencia y reintentos a alto nivel;
- valorar observabilidad y gestión de errores;
- diseñar automatizaciones con controles humanos cuando proceda.

## 4. Teoría

No toda tarea debe automatizarse. Se evaluarán:

- frecuencia;
- repetibilidad;
- riesgo;
- coste;
- excepciones;
- beneficio.

Una automatización fiable debe contemplar éxito, fallo, reintento, rollback o compensación y evidencia.

## 5. Herramientas

## 6. Ejercicios

- identificar operaciones no idempotentes;
- diseñar registro de errores.

## 7. Laboratorio

Diseñar un flujo automático de alta de usuario ficticio:

1. recibir solicitud;
2. validar datos;
3. crear recursos;
4. notificar;
5. registrar;
6. manejar fallo parcial;
7. definir intervención humana.
