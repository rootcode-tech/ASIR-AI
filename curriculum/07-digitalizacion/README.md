# ASIR-07 · Transformación Digital — Digitalización

**Estado:** especificación curricular completada  
**UDs:** 8

## Finalidad

Comprender cómo procesos, datos, conectividad, cloud, automatización, IA y ciberseguridad transforman organizaciones y servicios, manteniendo siempre una relación clara entre problema, tecnología, riesgo y valor.

## Principios

- digitalizar no es lo mismo que transformar;
- la tecnología se elige después de entender el problema;
- los datos deben tener calidad, ownership y gobierno;
- cloud es un modelo operativo, no solo infraestructura remota;
- automatizar requiere gestionar fallos y excepciones;
- la IA debe verificarse y nunca sustituye el criterio técnico;
- seguridad y privacidad se diseñan desde el principio;
- toda transformación debe tener métricas que permitan comprobar si aporta valor.
