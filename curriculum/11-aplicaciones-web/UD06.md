# ASIR-11 · UD06 — Reverse proxy, TLS, dominios y publicación segura

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- publicar aplicaciones mediante reverse proxy;
- configurar nombres DNS;
- desplegar TLS;
- comprender SNI;
- aplicar redirecciones HTTP→HTTPS;
- gestionar certificados;
- configurar headers de proxy;
- introducir seguridad de cabeceras;
- diagnosticar fallos de publicación.

## 2. Conocimientos previos

ASIR-10 UD02, UD04 y UD05; UD01-UD05 de ASIR-11.

## 3. Contenidos

- DNS;
- FQDN;
- reverse proxy;
- upstream;
- SNI;
- TLS;
- certificados;
- ACME a nivel conceptual;
- renovación;
- redirects;
- X-Forwarded-*;
- Host;
- headers de seguridad a nivel introductorio;
- health checks;
- rate limiting como contexto;
- logs.

## 4. Teoría

La publicación segura se verá como una cadena:

DNS → TLS → reverse proxy → aplicación → respuesta

Cada capa deberá poder validarse de forma independiente.

## 5. Herramientas

Nginx/HAProxy o equivalente, OpenSSL, curl y dig.

## 6. Ejercicios

- diseñar dominios;
- interpretar certificados;
- corregir SNI;
- configurar redirects;
- analizar 502/504;
- revisar headers.

## 7. Laboratorio

Publicar dos aplicaciones por HTTPS detrás de un reverse proxy, con nombres distintos y certificados de laboratorio.

## 8. Documentación y entregables

Configuración versionada, diagrama y procedimiento de renovación.

## 9. Competencias transversales

- DNS;
- TLS;
- seguridad;
- Git;
- troubleshooting.

## 10. Criterios de dominio

- publicar por nombre;
- gestionar TLS;
- configurar proxy;
- interpretar headers;
- diagnosticar publicación.

## 11. Preparación del examen

Casos de TLS/proxy.

## 12. Examen

- 30% DNS/TLS;
- 40% proxy;
- 30% diagnóstico.
