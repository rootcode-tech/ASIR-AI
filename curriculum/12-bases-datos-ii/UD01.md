# ASIR-12 · UD01 — Arquitectura interna y ciclo de vida de un SGBD

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-12 · Bases de Datos II — Administración de SGBD

## 1. Objetivos

- comprender la arquitectura interna básica de un SGBD;
- distinguir proceso servidor, instancia, base de datos y clúster lógico;
- comprender memoria, procesos internos y almacenamiento;
- relacionar WAL/redo con durabilidad;
- comprender catálogos del sistema;
- identificar fases de arranque y parada;
- interpretar arquitectura cliente-servidor del SGBD.

## 2. Conocimientos previos

ASIR-04 completo y ASIR-09 administración de sistemas.

## 3. Contenidos

- instancia;
- base de datos;
- procesos/background workers;
- shared buffers/cache;
- catálogos;
- data directory;
- WAL/redo log;
- checkpoint;
- startup/shutdown;
- conexiones;
- sesiones;
- parámetros;
- archivos de configuración;
- logs;
- ciclo de vida.

## 4. Teoría

Se estudiará el SGBD como sistema de infraestructura:

`cliente → proceso servidor → memoria → almacenamiento → WAL → persistencia`

El objetivo es dejar de ver la base como “tablas” y empezar a verla como servicio operativo.

## 5. Herramientas

PostgreSQL como SGBD principal, psql y herramientas del sistema operativo.

## 6. Ejercicios

- identificar componentes;
- interpretar procesos;
- localizar data directory;
- analizar logs de arranque;
- diferenciar instancia/base;
- explicar checkpoint/WAL a alto nivel.
