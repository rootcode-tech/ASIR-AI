# ASIR-11 · UD01 — Arquitectura web, HTTP y componentes de una aplicación

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- comprender la arquitectura de una aplicación web moderna;
- distinguir frontend, backend, base de datos, proxy y servicios auxiliares;
- comprender el flujo HTTP entre navegador, servidor y aplicación;
- diferenciar contenido estático y dinámico;
- identificar dependencias de una aplicación;
- comprender sesiones, cookies y estado a nivel funcional;
- interpretar una arquitectura de despliegue.

## 2. Conocimientos previos

ASIR-05 UD07, ASIR-10 UD04-UD05 y ASIR-04.

## 3. Contenidos

- cliente/servidor;
- navegador;
- servidor web;
- application server/runtime;
- reverse proxy;
- frontend/backend;
- base de datos;
- almacenamiento;
- caché;
- sesión;
- cookie;
- stateless/stateful;
- API;
- contenido estático/dinámico;
- dependencias;
- configuración;
- secrets;
- flujo request/response.

## 4. Teoría

La aplicación se estudiará como un conjunto de componentes con dependencias explícitas:

`cliente → DNS → TLS → reverse proxy → aplicación → base de datos/servicios`

La capacidad de diagnosticar cada salto será parte central del módulo.

## 5. Herramientas

curl, browser DevTools, Nginx/Apache, runtime de ejemplo, PostgreSQL y diagramación.

## 6. Ejercicios

- identificar componentes;
- dibujar flujos;
- distinguir 4xx/5xx;
- localizar estado;
- analizar dependencias;
- diagnosticar un request fallido.

## 7. Laboratorio

Desplegar una aplicación mínima con frontend, backend y base de datos, inicialmente sin contenedores.

## 8. Documentación y entregables

Diagrama de arquitectura y matriz de dependencias.

## 9. Competencias transversales

- HTTP;
- redes;
- bases de datos;
- documentación;
- troubleshooting.

## 10. Criterios de dominio

- describir una arquitectura;
- localizar responsabilidad de cada componente;
- seguir una petición extremo a extremo;
- distinguir estado y configuración;
- identificar dependencias.

## 11. Preparación del examen

Escenarios de arquitectura y flujo HTTP.

## 12. Examen

- 40% arquitectura;
- 30% HTTP;
- 30% diagnóstico.
