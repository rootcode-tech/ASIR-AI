# Fases de construcción del currículo

## Fase 0 — Estructura ✅

Repositorio, convenciones, directorios, fuente de verdad y contrato pedagógico.

## Fase 1 — Mapa de UDs ✅

Las 18 asignaturas están desglosadas en **172 unidades didácticas planificadas**.

## Fase 2 — Dependencias y progresión ✅

Mapa de prerrequisitos y roadmap de competencias transversales.

## Fase 3 — Especificación de cada UD ⏳

Para cada una de las 172 UDs se rellenará el contrato completo:

`objetivos → conocimientos previos → contenidos → teoría → herramientas → ejercicios → laboratorio → documentación → competencias transversales → criterios de dominio → preparación del examen → examen`

Se hará por asignatura, revisando cada bloque antes de pasar al siguiente.

## Fase 4 — Diseño de evaluación

Banco de preguntas, blueprint de exámenes, dificultad, cobertura y exámenes finales de asignatura.

## Fase 5 — Laboratorios y ejercicios

Construcción de prácticas reproducibles y ejercicios asociados a cada UD.

## Fase 6 — Proyecto integrador

Definición detallada del proyecto ASIR-AI, hitos, arquitectura, criterios de aceptación y defensa.

## Fase 7 — Currículo Maestro v1.0

Auditoría final de cobertura, secuencia, carga, solapamientos y coherencia. Solo después comenzará el estudio.
