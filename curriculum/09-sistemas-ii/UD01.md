# ASIR-09 · UD01 — Administración avanzada de GNU/Linux

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-09 · Sistemas II — Administración de Sistemas Operativos

## 1. Objetivos

- administrar sistemas GNU/Linux con enfoque profesional;
- comprender jerarquía de configuración y estado;
- gestionar cuentas, permisos, procesos y servicios con mayor profundidad;
- utilizar herramientas de administración remota;
- diagnosticar incidencias complejas;
- automatizar tareas repetitivas de forma controlada;
- mantener el sistema actualizado y documentado.

## 2. Conocimientos previos

ASIR-01 completo, especialmente UD05-UD10.

## 3. Contenidos

- administración multiusuario;
- sudoers;
- PAM a nivel introductorio;
- systemd avanzado;
- units personalizadas;
- journald;
- cron y timers;
- SSH;
- configuración de red desde sistema;
- paquetes y repositorios;
- variables y entorno;
- límites de recursos;
- ulimit;
- kernel/modules a nivel funcional;
- sysctl;
- mantenimiento;
- troubleshooting.

## 4. Teoría

La administración avanzada se organizará alrededor de cuatro planos:

`identidad → proceso/servicio → recurso → evidencia`

El objetivo es pasar de “usar Linux” a **operar Linux**.

## 5. Herramientas

- systemctl/journalctl;
- ssh;
- sudo;
- sysctl;
- herramientas de procesos;
- gestor de paquetes;
- editor de texto;
- Git para versionar configuración/documentación.

## 6. Ejercicios

- crear units;
- ajustar límites;
- administrar sudo;
- revisar logs;
- endurecer SSH;
- diagnosticar servicios;
- comparar configuración persistente y temporal.

## 7. Laboratorio

Preparar un servidor Linux para uso interno:

1. usuarios;
2. sudo;
3. SSH;
4. servicios;
5. logs;
6. actualizaciones;
7. hardening básico;
8. documentación.

## 8. Documentación y entregables

Runbook del servidor y baseline de configuración.

## 9. Competencias transversales

- Linux;
- seguridad;
- Git;
- troubleshooting;
- documentación.

## 10. Criterios de dominio

- administrar sin depender de GUI;
- localizar configuración/estado;
- diagnosticar por evidencia;
- aplicar cambios reversibles;
- documentar operación.

## 11. Preparación del examen

Casos de administración real y diagnóstico.

## 12. Examen

- 30% administración;
- 30% configuración;
- 40% troubleshooting.
