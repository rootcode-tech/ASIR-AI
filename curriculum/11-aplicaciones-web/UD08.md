# ASIR-11 · UD08 — CI/CD introductorio para despliegues

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- comprender integración y entrega/despliegue continuos;
- identificar etapas de pipeline;
- automatizar validaciones;
- comprender artefactos;
- ejecutar despliegues controlados;
- introducir rollback;
- separar CI de CD;
- gestionar secretos del pipeline de forma segura;
- preparar ASIR-16.

## 2. Conocimientos previos

## 4. Teoría

Un pipeline se enseñará como procedimiento ejecutable y auditable.

Secuencia mínima:

commit → validar → construir → desplegar a staging → probar → aprobar → producción

ASIR-16 profundizará en diseño profesional de CI/CD.

## 5. Herramientas

GitHub Actions u otra plataforma CI de referencia, Git y shell.

## 6. Ejercicios

- diseñar pipelines;
- diferenciar CI/CD;
- detectar secretos inseguros;
- analizar fallos;
- definir quality gates.

## 7. Laboratorio

Crear un pipeline que valide una app, construya artefacto o imagen y despliegue a un entorno de laboratorio.

## 8. Documentación y entregables

Workflow versionado y diagrama del pipeline.

## 9. Competencias transversales

## 10. Criterios de dominio

## 11. Preparación del examen

Lectura y diseño de pipelines.
