# ASIR-17 · UD04 — Plataforma base: red, sistemas, identidad y almacenamiento

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-17 · Proyecto ASIR-AI

## 1. Objetivos

- desplegar la plataforma base;
- implementar red y segmentación;
- desplegar Linux/Windows cuando aporte valor;
- integrar identidad;
- preparar almacenamiento;
- aplicar hardening inicial;
- documentar configuración;
- validar conectividad y dependencias.

## 2. Conocimientos previos

UD01-UD03 y ASIR-01/02/03/09/13.

- storage;

- remote administration;
- baseline;
- hardening;

## 4. Teoría

La plataforma base se desplegará por capas y con validaciones intermedias.

Secuencia:

`red → hosts → identidad → storage → hardening → validación`

## 5. Herramientas

Hipervisor, Linux, Windows Server, Ansible cuando proceda, herramientas de red y Git.

- verificar storage;
- aplicar baseline.
