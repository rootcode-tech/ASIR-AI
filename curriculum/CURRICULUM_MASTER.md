# Currículo Maestro ASIR-AI

**Versión:** 0.1.0-draft  
**Estado:** estructura inicial  
**Marca:** RootCode Technologies

## Objetivo

Construir primero el currículo completo de ASIR-AI y, únicamente después, comenzar el estudio secuencial.

## Modelo pedagógico

Cada asignatura se divide en unidades didácticas. Cada UD seguirá este contrato:

`UD → contenidos → objetivos → conocimientos previos → teoría → ejercicios → laboratorio → herramientas → documentación → competencias transversales → criterios de dominio → preparación del examen → examen`
