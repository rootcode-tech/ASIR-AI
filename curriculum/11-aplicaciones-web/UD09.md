# ASIR-11 · UD09 — Seguridad, backups y mantenimiento de aplicaciones

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- mantener aplicaciones web de forma segura;
- aplicar actualizaciones;
- comprender gestión de vulnerabilidades;
- realizar backups consistentes;
- restaurar aplicación y datos;
- aplicar mínimo privilegio;
- revisar permisos y superficie expuesta;
- gestionar ventanas de mantenimiento;
- documentar incidentes y cambios.

## 2. Conocimientos previos

UD01-UD08 y ASIR-09 UD09/UD11.

## 3. Contenidos

- patching;

- maintenance mode;

- logging;
- audit trail;
- change management;
- rollback.

## 4. Teoría

La seguridad de una aplicación desplegada depende tanto del código como de la infraestructura y la operación.

Se priorizará:

inventario → parcheo → mínimo privilegio → backup → observación → respuesta

## 5. Herramientas

Gestores de paquetes, scanners de dependencias a nivel contextual, backup tools y logs.

## 6. Ejercicios

- evaluar parche;
- diseñar backup;
- detectar permisos excesivos;
- planificar mantenimiento;
- interpretar vulnerabilidades;
- diseñar rollback.

## 7. Laboratorio

Actualizar una aplicación con base de datos:

1. backup;
2. snapshot si procede;
3. mantenimiento;
4. actualización;
5. pruebas;
6. fallo simulado;
7. rollback/restore.

## 8. Documentación y entregables

Plan de mantenimiento y acta de recuperación.

## 10. Criterios de dominio

Casos de mantenimiento y seguridad.
