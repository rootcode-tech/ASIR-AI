# ASIR-13 · UD12 — Laboratorio integral de seguridad y resiliencia

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-13 · Ciberseguridad y Alta Disponibilidad

## 1. Objetivos

- integrar seguridad preventiva, detección, respuesta y continuidad;
- diseñar una arquitectura resiliente;
- aplicar hardening;
- segmentar;
- monitorizar;
- gestionar vulnerabilidades;
- responder a incidentes;
- ejecutar failover/restore;
- producir documentación completa.

## 2. Conocimientos previos

UD01-UD11.

## 3. Contenidos

- riesgo;
- hardening;
- IAM;
- segmentation;
- firewall;
- detection;
- vulnerability management;
- web security;
- backup;
- HA;
- incident response;
- audit;
- recovery;
- postmortem.

## 4. Teoría

El laboratorio sigue el ciclo:

`prevenir → detectar → responder → recuperar → aprender`

La seguridad se evaluará como propiedad operativa del sistema completo.

## 5. Herramientas

Todas las herramientas defensivas del módulo.

## 6. Ejercicios

- threat model;
- revisión de arquitectura;
- plan de detección;
- plan de continuidad;
- tabletop;
- hardening review.

## 7. Laboratorio

### Escenario integral

Infraestructura con:

- usuarios;
- servidores;
- DMZ;
- aplicación web;
- base de datos;
- VPN;
- backups;
- monitorización.

Se introducirán fallos y eventos controlados para comprobar:

1. prevención;
2. detección;
3. contención;
4. failover o restore;
5. recuperación;
6. auditoría;
7. postmortem.

## 9. Competencias transversales

## 10. Criterios de dominio

- integrar controles coherentes;
- detectar fallos;
- preservar evidencia;
- recuperar servicio;
- explicar trade-offs;
- documentar de forma auditable.
