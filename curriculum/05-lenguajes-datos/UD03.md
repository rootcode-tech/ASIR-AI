# ASIR-05 · UD03 — XML bien formado, namespaces y modelos de documento

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-05 · Lenguajes y Datos — Lenguajes de Marcas y SGI

## 1. Objetivos

- comprender XML como lenguaje extensible de datos;
- construir documentos bien formados;
- distinguir elementos, atributos y texto;
- comprender namespaces;
- diseñar estructuras jerárquicas;
- interpretar documentos XML;
- comparar XML con HTML y JSON.

## 2. Conocimientos previos

UD01 recomendada.

## 3. Contenidos

- declaración XML;
- elementos;
- atributos;
- anidamiento;
- caracteres especiales;
- CDATA;
- comentarios;
- documento bien formado;
- namespaces;
- prefijos;
- URI de namespace;
- árbol XML;
- serialización.

## 4. Teoría

XML se estudiará como representación estructurada y autodescriptiva. Se insistirá en distinguir:

`bien formado` de `válido`.

## 5. Herramientas

Editor XML, parser/validador y navegador.

## 6. Ejercicios

- corregir XML mal formado;
- diseñar árboles;
- usar namespaces;
- transformar datos tabulares a XML;
- comparar estructuras XML/JSON.

## 7. Laboratorio

Modelar inventario IT en XML con equipos, interfaces, propietarios y ubicación, usando namespace propio.

## 8. Documentación y entregables

Documento XML y esquema conceptual de estructura.

## 9. Competencias transversales

- estructuras de datos;
- documentación;
- interoperabilidad.

## 10. Criterios de dominio

- crear XML bien formado;
- explicar namespaces;
- leer estructura jerárquica;
- detectar errores sintácticos.

## 11. Preparación del examen

Corrección y diseño de XML.

## 12. Examen

- 60% práctica XML;
- 20% namespaces;
- 20% interpretación.
