# ASIR-AI

**RootCode Technologies · ASIR-AI**

Currículo maestro abierto para una formación completa en Administración de Sistemas Informáticos en Red, ampliada con prácticas profesionales actuales de Linux, redes, automatización, Git, DevOps, cloud, ciberseguridad, observabilidad e IA aplicada.

## Estado

El proyecto está en **fase de diseño curricular**. Antes de comenzar a estudiar se cerrará el currículo maestro completo de las 18 asignaturas y su secuencia de unidades didácticas.

## Principios

- El currículo oficial de ASIR es la base.
- Las tecnologías modernas se integran de forma transversal y cuando existen los prerrequisitos adecuados.
- Markdown es la fuente de verdad pedagógica.
- YAML contiene metadatos estructurados para automatización.
- Git conserva la evolución y trazabilidad del curso.
- Los ejercicios y laboratorios sirven para aprender; la nota se obtiene mediante exámenes.
- Cada UD debe terminar con criterios de dominio verificables.
- La IA se usa como herramienta técnica, nunca como sustituto de la comprensión ni de la validación.

## Estructura

```text
curriculum/   Currículo maestro y asignaturas
transversal/  Competencias y tecnologías transversales
exercises/    Ejercicios
labs/         Laboratorios prácticos
exams/        Exámenes y bancos de evaluación
project/      Proyecto integrador ASIR-AI
docs/         Normas, metodología y documentación del curso
```

## Fuente de verdad

1. `curriculum/CURRICULUM_MASTER.md` — mapa pedagógico completo.
2. `curriculum/curriculum.yml` — índice estructurado.
3. `curriculum/<asignatura>/README.md` — definición de cada asignatura.
4. `curriculum/<asignatura>/UDxx.md` — desarrollo de cada unidad.
