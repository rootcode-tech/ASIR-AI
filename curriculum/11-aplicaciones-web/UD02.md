# ASIR-11 · UD02 — Servidores web, virtual hosts y runtime de aplicaciones

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-11 · Web e Infraestructura — Implantación de Aplicaciones Web

## 1. Objetivos

- configurar servidores web para aplicaciones;
- comprender virtual hosts/sites;
- integrar un runtime;
- gestionar procesos de aplicación;
- configurar permisos y usuarios de servicio;
- comprender variables de entorno;
- gestionar logs;
- diagnosticar fallos de runtime.

## 2. Conocimientos previos

UD01 y ASIR-10 UD04.

## 3. Contenidos

- Nginx/Apache;
- virtual hosts;
- document root;
- proxy_pass/FastCGI según stack;
- runtime;
- procesos;
- service units;
- variables de entorno;
- usuarios de servicio;
- permisos;
- logs;
- sockets Unix/TCP;
- restart/reload;
- health check.

## 4. Teoría

Se separará con claridad:

- servidor web;
- proceso de aplicación;
- runtime;
- socket;
- contenido;
- configuración.

## 5. Herramientas

Nginx/Apache, systemd, runtime de ejemplo y curl.

## 6. Ejercicios

- configurar sites;
- conectar runtime;
- analizar permisos;
- interpretar logs;
- diferenciar reload/restart;
- resolver errores de socket.

## 7. Laboratorio

Publicar una aplicación mediante Nginx/Apache y un servicio systemd, con usuario dedicado y logs separados.

## 8. Documentación y entregables

Configuración versionada y runbook de operación.

## 9. Competencias transversales

- Linux;
- systemd;
- HTTP;
- Git;
- troubleshooting.

## 10. Criterios de dominio

- conectar web server y runtime;
- operar servicio;
- gestionar permisos;
- diagnosticar 502/503;
- versionar configuración.

## 11. Preparación del examen

Configuración y troubleshooting.

## 12. Examen

- 60% práctica;
