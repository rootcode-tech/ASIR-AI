# ASIR-09 · UD07 — Tareas programadas, systemd timers y operación repetible

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-09 · Sistemas II — Administración de Sistemas Operativos

## 1. Objetivos

- programar tareas en Linux y Windows;
- distinguir ejecución manual y programada;
- comprender cron y systemd timers;
- comprender Task Scheduler y automatización PowerShell;
- diseñar tareas repetibles e idempotentes;
- registrar resultados;
- manejar concurrencia y locks básicos;
- detectar y recuperar fallos.

## 2. Conocimientos previos

## 4. Teoría

Una tarea programada no debe depender de supuestos invisibles del entorno interactivo.

Se validará:

`entrada → entorno → ejecución → resultado → log → reintento/alerta`

## 5. Herramientas

cron, systemd timers, Task Scheduler, PowerShell y logs.

## 6. Ejercicios

- traducir frecuencias;
- diseñar timers;
- analizar fallos por PATH/permisos;
- evitar dobles ejecuciones;
- crear logs.

## 7. Laboratorio

Programar inventario y backup en Linux y Windows, con logs, control de errores y verificación posterior.
