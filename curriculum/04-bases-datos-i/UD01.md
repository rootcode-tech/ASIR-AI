# ASIR-04 · UD01 — Sistemas de información y modelos de datos

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-04 · Bases de Datos I — Gestión de Bases de Datos

## 1. Objetivos

- explicar qué problema resuelve una base de datos;
- distinguir dato, información, metadato y conocimiento;
- diferenciar fichero, base de datos y SGBD;
- comprender independencia lógica y física de los datos;
- identificar modelos de datos;
- reconocer roles de usuario, desarrollador y administrador;
- entender integridad, persistencia, concurrencia y seguridad como propiedades del sistema.

## 2. Conocimientos previos

Competencia digital básica y razonamiento lógico de ASIR-00.

## 3. Contenidos

### 3.1 Conceptos

- dato e información;
- sistema de información;
- base de datos;
- SGBD;
- esquema e instancia;
- metadatos;
- independencia de datos;
- modelos jerárquico, red, relacional, documental y clave-valor a nivel introductorio;
- transacción;
- integridad;
- concurrencia;
- persistencia;
- seguridad;
- disponibilidad;
- roles y responsabilidades.

### 3.2 Procedimientos

- identificar entidades informativas de un caso;
- distinguir estructura de datos y datos concretos;
- seleccionar un modelo adecuado a nivel conceptual;
- detectar redundancia en soluciones basadas en ficheros;
- describir requisitos de una base de datos.

### 3.3 Diagnóstico

Errores frecuentes:

- usar hoja de cálculo como sustituto universal de una base de datos;
- confundir SGBD con base de datos;
- asumir que más tablas implica mejor diseño;
- mezclar diseño lógico con implementación física.

## 4. Teoría

Se estudiará la evolución:

`ficheros aislados → problemas de redundancia/inconsistencia → SGBD → modelos de datos → diseño estructurado`

El objetivo es comprender por qué existe la disciplina de bases de datos antes de escribir SQL.

## 6. Ejercicios

1. Clasificar diez sistemas según necesiten o no SGBD.
2. Identificar datos, metadatos y reglas de negocio.
3. Detectar redundancias de un sistema de ficheros.
4. Comparar relacional y documental a alto nivel.
5. Definir requisitos de persistencia para un sistema pequeño.

## 7. Laboratorio

Analizar una aplicación ficticia de inventario mantenida mediante hojas de cálculo y proponer qué problemas aparecen al crecer: duplicidad, concurrencia, seguridad, integridad y trazabilidad.

## 8. Documentación y entregables
