# ASIR-00 · UD02 — Números y cálculo: aritmética, proporcionalidad, porcentajes y matemática financiera

**Estado:** especificación curricular completa  
**Versión:** 0.2.0  
**Asignatura:** ASIR-00 · Preparación de acceso a Grado Superior  
**Alineación:** Competencia matemática N4 · dominio Números y Cálculo (NC4)

## 1. Objetivos

- operar con enteros, decimales, fracciones, potencias y raíces;
- respetar prioridad de operaciones y unidades;
- interpretar razones, proporciones y tasas;
- resolver proporcionalidad directa, inversa y compuesta;
- resolver repartos proporcionales, mezclas y problemas de trabajo simultáneo;
- calcular porcentajes, aumentos, descuentos y variaciones sucesivas;
- aplicar porcentajes a documentos y situaciones económicas reales;
- comprender interés simple y compuesto;
- interpretar tablas, facturas, nóminas y datos financieros básicos;
- manejar notación científica, órdenes de magnitud y conversiones;
- distinguir bits/bytes y prefijos decimales/binarios;
- estimar y verificar resultados.

## 3. Método de resolución

Para problemas verbales:

```text
datos → relación entre magnitudes → operación/modelo → cálculo → unidad → estimación → comprobación
```

No se enseñará la regla de tres como algoritmo ciego. Primero se decide qué relación existe.

## 4. Errores frecuentes

- confundir porcentaje con puntos porcentuales;
- aplicar porcentajes sucesivos sumándolos;
- usar el valor final como base cuando corresponde el inicial;
- invertir una proporcionalidad;
- mezclar bits y bytes;
- mezclar prefijos decimales y binarios;
- perder unidades;
- aceptar resultados absurdos sin estimarlos.

## 5. Práctica

Se usarán datos variables entre intentos y contextos diferentes para evitar memorización.

Ejemplos:
- mezclas/concentraciones;
- trabajo simultáneo;
- reparto proporcional;
- crecimiento compuesto;
- descuentos sucesivos;
- transferencia de datos;
- consumo/ocupación de recursos.

## 6. Criterios de dominio

El alumno debe poder:
- elegir el procedimiento sin que el enunciado le diga qué fórmula usar;
- resolver proporcionalidad directa/inversa/compuesta;
- trabajar con porcentajes encadenados;
- resolver mezclas y tasas de trabajo;
- interpretar interés simple/compuesto;
- mantener unidades coherentes;
- detectar errores de factor 8 o de orden de magnitud;
- justificar y comprobar el resultado.

- 8 preguntas;
- 20 minutos;
- cuatro opciones y una correcta;
- datos y contextos nuevos;
- estrategia de descarte de distractores basada en razonamiento.
