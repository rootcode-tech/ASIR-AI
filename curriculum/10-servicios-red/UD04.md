# ASIR-10 · UD04 — Servicios web HTTP/HTTPS y servidores web

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-10 · Servicios de Red e Internet

## 1. Objetivos

- comprender arquitectura web;
- desplegar servidores HTTP;
- configurar virtual hosts/sites;
- interpretar métodos, status y headers;
- gestionar contenido estático;
- comprender MIME;
- diagnosticar errores 4xx/5xx;
- administrar logs de acceso/error.

## 2. Conocimientos previos

ASIR-05 UD07 y UD01 de ASIR-10.

## 3. Contenidos

- HTTP;
- request/response;
- methods;
- status;
- headers;
- Host;
- virtual hosts;
- document root;
- MIME;
- redirects;
- compression a nivel funcional;
- caching headers a nivel introductorio;
- logs;
- Apache/Nginx;
- permissions;
- systemd service.

## 4. Teoría

El servidor web se estudiará como software de publicación y proxy, separándolo de la aplicación.

## 5. Herramientas

Nginx y/o Apache, curl, browser DevTools, logs.

## 6. Ejercicios

- interpretar requests;
- configurar sites;
- redirecciones;
- permisos;
- analizar 404/403/500;
- leer access logs.

## 7. Laboratorio

Publicar dos sitios por nombre en el mismo servidor, configurar logs separados y validar desde curl/navegador.

## 8. Documentación y entregables

Configuración versionada y runbook.

## 9. Competencias transversales

- Linux;
- HTTP;
- DNS;
- observabilidad;
- Git.

## 10. Criterios de dominio

- publicar virtual hosts;
- interpretar HTTP;
- diagnosticar permisos/configuración;
- usar logs;
- reproducir despliegue.

## 11. Preparación del examen

Configuración y análisis de errores.

## 12. Examen

- 30% HTTP;
- 40% administración;
- 30% troubleshooting.
