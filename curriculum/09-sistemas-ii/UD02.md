# ASIR-09 · UD02 — Windows Server y administración remota

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-09 · Sistemas II — Administración de Sistemas Operativos

## 1. Objetivos

- instalar y preparar Windows Server;
- administrar roles y características;
- comprender Server Manager y administración remota;
- trabajar con PowerShell de forma habitual;
- gestionar servicios, almacenamiento y red;
- comprender Windows Admin Center a nivel funcional;
- aplicar actualizaciones y mantenimiento;
- diagnosticar eventos y servicios.

## 2. Conocimientos previos

ASIR-01 UD08 y fundamentos de redes.

## 3. Contenidos

- Windows Server;
- Server Core/Desktop Experience como concepto;
- roles/features;
- Server Manager;
- PowerShell;
- PowerShell Remoting;
- WinRM;
- servicios;
- Event Viewer;
- almacenamiento;
- networking;
- updates;
- Windows Admin Center;
- administración remota;
- políticas locales;
- troubleshooting.

## 4. Teoría

La administración remota será el enfoque principal. PowerShell no se tratará como accesorio, sino como interfaz administrativa reproducible.

## 5. Herramientas

PowerShell, Server Manager, Windows Admin Center, Event Viewer y herramientas de red.

## 6. Ejercicios

- instalar roles;
- consultar estado por PowerShell;
- administrar servicios;
- realizar inventario remoto;
- filtrar eventos;
- resolver incidencias.

## 7. Laboratorio

Desplegar dos Windows Server y administrar uno desde el otro de forma remota, documentando roles, red, eventos y actualizaciones.

## 8. Documentación y entregables

Script de inventario y runbook de administración remota.

## 9. Competencias transversales

- PowerShell;
- Windows;
- automatización;
- seguridad;
- observabilidad.

## 10. Criterios de dominio

- gestionar roles;
- usar remoting;
- automatizar inventario;
- interpretar eventos;
- administrar sin depender exclusivamente de GUI.

## 11. Preparación del examen

Tareas PowerShell y escenarios de administración.

## 12. Examen

- 50% práctica;
- 25% administración remota;
- 25% diagnóstico.
