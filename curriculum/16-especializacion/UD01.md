# ASIR-16 · UD01 — Flujo profesional con Git, ramas, PR, releases y SemVer

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-16 · Especialización — DevOps, Cloud e IA para Sistemas

## 1. Objetivos

- trabajar con Git en flujo profesional;
- comprender ramas, merges y conflictos;
- utilizar pull requests;
- aplicar code review;
- comprender tags y releases;
- aplicar Semantic Versioning;
- mantener changelog;
- proteger ramas y definir quality gates básicos;
- relacionar Git con trazabilidad y colaboración.

## 2. Conocimientos previos

Git/GitHub introducido en ASIR-05 y utilizado de forma transversal.

## 3. Contenidos

- branch;
- merge;
- rebase a nivel funcional;
- conflict;
- pull request;
- code review;
- protected branch;
- status checks;
- tag;
- release;
- SemVer;
- changelog;
- conventional commits como patrón opcional;
- issue;
- milestone;
- release notes;
- hotfix;
- rollback.

## 4. Teoría

Git deja de ser un sistema para “guardar cambios” y pasa a ser el eje de colaboración, revisión y entrega.

Flujo de referencia:

`issue → branch → commits → PR → review → checks → merge → tag → release`

## 5. Herramientas

Git, GitHub, GitHub CLI a nivel contextual y Markdown.

## 6. Ejercicios

- resolver conflictos;
- abrir PR;
- revisar cambios;
- crear tags;
- aplicar SemVer;
- redactar release notes;
- revertir cambios.

## 7. Laboratorio

Gestionar una mini-release completa de un proyecto técnico con ramas, PR, revisión, checks, tag y release.

## 8. Documentación y entregables

Historial Git, PRs, changelog y release.

## 9. Competencias transversales

- Git/GitHub;
- colaboración;
- documentación;
- calidad.

## 10. Criterios de dominio

- trabajar con ramas sin perder historial;
- resolver conflictos;
- usar PR;
- versionar correctamente;
- mantener trazabilidad.

## 11. Preparación del examen

Escenarios de flujo Git.

## 12. Examen

- 40% conceptos;
- 40% práctica;
- 20% resolución de conflictos.
