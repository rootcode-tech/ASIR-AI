## 4. Teoría

El DDL debe convertir el diseño lógico en **reglas ejecutables**. No basta con crear columnas: la base de datos debe rechazar estados inválidos.

Se priorizarán tipos y restricciones portables, explicando diferencias de PostgreSQL/MariaDB cuando sean relevantes.
