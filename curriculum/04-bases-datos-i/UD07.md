# ASIR-04 · UD07 — Consultas SELECT, funciones, agregación y ordenación

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-04 · Bases de Datos I — Gestión de Bases de Datos

## 1. Objetivos

- recuperar datos con SELECT;
- filtrar mediante WHERE;
- ordenar y limitar resultados;
- usar expresiones y alias;
- trabajar con NULL correctamente;
- utilizar funciones escalares habituales;
- agrupar y agregar;
- filtrar grupos con HAVING;
- interpretar el orden lógico de una consulta.

## 2. Conocimientos previos

UD05-UD06.

## 3. Contenidos

- SELECT;
- FROM;
- WHERE;
- DISTINCT;
- ORDER BY;
- LIMIT/FETCH;
- alias;
- operadores;
- LIKE;
- IN;
- BETWEEN;
- IS NULL;
- CASE;
- funciones de texto, numéricas y fecha;
- COUNT, SUM, AVG, MIN, MAX;
- GROUP BY;
- HAVING;
- orden lógico de procesamiento.

## 4. Teoría

Se diferenciará claramente:

- filtrar filas con WHERE;
- formar grupos con GROUP BY;
- filtrar grupos con HAVING.

También se trabajará la lógica de tres valores de NULL.

## 5. Herramientas

PostgreSQL y cliente SQL.

## 6. Ejercicios

Al menos 50 consultas progresivas:

- filtros;
- orden;
- expresiones;
- CASE;
- funciones;
- agregaciones;
- agrupaciones;
- HAVING.

## 7. Laboratorio

Responder mediante consultas a un conjunto de preguntas de negocio sobre inventario, incidencias o ventas, sin modificar datos.

## 8. Documentación y entregables

Archivo `queries-basic.sql` comentado.

## 9. Competencias transversales

- análisis de datos;
- SQL;
- documentación;
- razonamiento lógico.

## 10. Criterios de dominio

- escribir consultas sin depender de GUI;
- manejar NULL;
- agrupar correctamente;
- explicar el resultado antes de ejecutar;
- producir consultas legibles.

## 11. Preparación del examen

Consultas nuevas sobre un esquema conocido.

## 12. Examen

- 80% SQL práctico;
- 20% interpretación/explicación.
