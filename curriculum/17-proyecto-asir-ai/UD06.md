# ASIR-17 · UD06 — Datos, aplicaciones y persistencia

**Estado:** especificación curricular completa  
**Versión:** 0.1.0  
**Asignatura:** ASIR-17 · Proyecto ASIR-AI

## 1. Objetivos

- desplegar capa de datos y aplicaciones;
- integrar bases de datos con aplicaciones;
- diseñar persistencia;
- separar datos, configuración y secretos;
- aplicar mínimo privilegio;
- gestionar migrations y backups;
- validar integridad;
- documentar dependencias y recuperación.

## 2. Conocimientos previos

UD01-UD05 y ASIR-04/11/12.

## 3. Contenidos

- database;
- schema;
- migrations;
- application runtime;
- container;
- storage;
- volume;
- connection;
- secrets;
- service accounts;
- least privilege;
- backup;
- restore;
- replication cuando proceda;
- consistency;
- persistence;
- lifecycle.

## 4. Teoría

La capa de datos se diseñará para ser:

- persistente;
- recuperable;
- segura;
- observable;
- desacoplada de la configuración.

## 5. Herramientas

PostgreSQL, Docker/Compose cuando aporte valor, runtime de aplicación, Git y herramientas de backup.

## 6. Ejercicios

- diseñar usuarios;
- aplicar migrations;
- validar backups;
- separar secrets;
- probar restore;
- revisar persistencia.

## 7. Laboratorio

Desplegar la aplicación del proyecto con su capa de datos, almacenamiento persistente, usuarios restringidos y procedimiento de backup/restore.

## 8. Documentación y entregables

Modelo de datos, procedimientos, scripts, pruebas y matriz de privilegios.

## 9. Competencias transversales

- bases de datos;
- aplicaciones;
- contenedores;
- seguridad;
- recuperación.

## 10. Criterios de dominio

- desplegar aplicación/datos;
- aplicar mínimo privilegio;
- persistir;
- recuperar;
- validar integridad.

## 11. Preparación del examen

Casos de aplicación + datos.

## 12. Examen

- 30% arquitectura;
- 30% persistencia;
- 20% seguridad;
- 20% recuperación.
